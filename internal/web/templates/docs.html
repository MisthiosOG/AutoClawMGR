GET /v1/models

POST /v1/chat/completions
Send a chat completion request. OpenAI-compatible format.
curl -X POST {{.BaseURL}}/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5-turbo","messages":[{"role":"user","content":"halo"}]}'
Parameters
Parameter Type Description
model string Model ID (e.g., glm-5-turbo, glm-5.3, deepseek-v4-pro)
messages array Chat messages [{role, content}]
stream bool Enable SSE streaming (default: false)
max_tokens int Maximum tokens in response
Authentication
If an API key is configured in Settings, include it as a header:
curl -H "Authorization: Bearer YOUR_KEY" {{.BaseURL}}/v1/models
